# Asset ownership

Keep the main temoto extension and website independently built. The former standalone Proxy source and its assets remain for existing users and migration; the main build must not depend on its runtime or icon generator. Share design sources and capture tools.

## Logos and fonts

- Canonical mark: [`browser/shared/temoto-mark.svg`](../browser/shared/temoto-mark.svg).
- PNG renderer: [`browser/shared/icon-utils.mjs`](../browser/shared/icon-utils.mjs). The core extension uses the solid mark; Proxy uses the hollow counterpart, with a stronger inward stroke at 16px.
- Core icons: `browser/temoto-chrome/public/icons/`, regenerated by that product's `npm run build:icons`.
- Proxy icons: generated by its `npm run build` into `dist/client/icons/`; do not edit the output directly.
- Website marks: `site/public/temoto-mark.svg` and `temoto-proxy-mark.svg`. Existing tests verify their geometry against the shared mark.
- Website font: `site/public/brand/Geist-Variable.woff2` and its adjacent license. Both the website and current Store capture stage use it. Extension Latin fonts come from each product's dependencies.
- Core UI and video-rate badges: the same bundled Geist font in `browser/temoto-chrome/public/fonts/`, with its adjacent license and source notes. Core UI is English-only; technical color values and capture dimensions continue to use IBM Plex Mono.

The selected direction was B / Joint (September 12, 2026): two angular pieces separated by a 30-degree diagonal gap, in a 160 × 160 frame. A / Cradle and C / Letterform were not adopted. The exploratory boards, duplicate SVG, preview page, and preview-only font were removed after the shared mark became the production source. Their original files and prompts remain in Git history.

## Store artwork

The authoritative submission images live in each extension's `store/assets/`, alongside its `store/listing.md`. Keep these and the local `release/` ZIPs separate from website captures.

Use [`browser/shared/STORE-CAPTURE.md`](../browser/shared/STORE-CAPTURE.md) and `serve-store-capture.mjs` for new screenshots. The older standalone frame has been retired. Captures use built UI with sample data; they do not prove installed-extension behavior or real proxy traffic.

## Website assets

- `site/app/components/launcher-preview.tsx` renders the five-tool product illustration as HTML and CSS, following the selected landing-page design. It is a static overview, not an operating extension. Its SVG icons in `site/public/tools/` come from the extension's existing `@phosphor-icons/react` 2.1.10 library, with its MIT license retained.
- `site/public/showcase/chrome-launcher.png` remains the original five-row product capture used in the OG template: PNG, 416 × 402, SHA-256 prefix `47ae7d5e3c53`, captured October 13, 2026. `proxy-popup.png` remains a historical standalone-Proxy capture and is not shown as the integrated UI.
- `site/public/product-*` retains canonical Store-image copies and icons. `npm run sync:product-icons` in `site/` refreshes only the main Chrome icon and launcher, and also runs before development and builds. Existing `product-proxy-*` files are historical copies; they are preserved without requiring legacy Proxy code during the site build.
- The page keeps the original temoto mark and Geist font. Its headline uses Inter Bold from Google Fonts, stored with its SIL Open Font License under `site/public/brand/`. All fonts are served locally.
- `site/public/og-temoto.png` is the 1200 × 630 share image. Its existing template and rendering command are in `site/scripts/`.

Image formats, dimensions, and saved-image appearance were checked. Earlier four-tool launcher artwork has been replaced; standalone Proxy artwork remains historical. Tests check server-rendered copy and tool names, the single Store action and preview notice, retained asset consistency, and OG image dimensions.
